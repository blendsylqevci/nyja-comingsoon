# NYJA project rules

## Global theme system (light / dark) — applies to every screen and component
- Every DC loads `nyja-theme.css` in `<helmet>` right after the design-system `styles.css`.
- The page root carries `data-theme="{{ theme }}"`; the logic class resolves theme = state → `theme` tweak prop (light | dark | system) → `localStorage['nyja-theme']` → 'light'. The service bar has the sun/moon toggle (`toggleTheme`), which persists to that key. `system` follows the OS (listen to `prefers-color-scheme` changes and `forceUpdate`).
- Inline styles never use hard-coded neutrals. Surface tokens: `--s-bg`, `--s-fg`, `--s-muted`, `--s-subtle`, `--s-faint`, `--s-field` (image/media placeholder), `--s-field-2` (soft control bg, band), `--s-divider` (soft rule), `--s-line` (strong rule), `--s-hover`, `--s-edge` (transparent in light, hairline in dark — put `border:1.5px solid var(--s-edge)` on every soft-filled control and every rounded dark panel so it never merges with a dark page), `--s-media` + `--s-media-faint` (black video/media tiles). Neon `#D5FF00` / `#C2E900` and black-on-neon stay literal.
- Theme-specific assets: render both variants and toggle with `display:var(--on-light)` / `display:var(--on-dark)` — e.g. the header wordmark is `wordmark-duo-light.png` + `wordmark-duo-dark.png`. Never recolor a logo. Assets inside inverse blocks (footer) always use the dark-surface variant.
- Inverse blocks (hero, campaigns, footer, black panels) prepend the `NYJA_INVERSE` override string to their inline style, then use `background:var(--s-bg);color:var(--s-fg)`. Children need no changes.
  `NYJA_INVERSE = --s-bg:var(--s-block);--s-fg:var(--s-block-fg);--s-muted:var(--s-block-muted);--s-subtle:var(--s-block-subtle);--s-faint:var(--s-block-faint);--s-field:var(--s-block-field);--s-field-2:var(--s-block-hover);--s-divider:var(--s-block-line);--s-line:var(--s-block-line);--s-hover:var(--s-block-hover)`
- White chips that sit on imagery use the `NYJA_CHIP` override (literal white + light tokens); video/media tiles use `NYJA_MEDIA` (`--s-bg:var(--s-media)` … `border:1.5px solid var(--s-edge)`); the one neon block per page uses `NYJA_NEON`, which also pins the DS tokens (`--ink:#000;--paper:#fff;--text-primary:#000;--gray-*` light values) so design-system controls on neon look identical in both themes.
- `NYJA-ProductCard` prop `theme`: `auto` (inherits the surface) or `inverse` (on a dark panel: white-on-black controls). Never hard-code card colors.
- `NYJA-ProductCard` product flag `fast: true` = local Kosovo stock eligible for 24h delivery → neon "24h" pill next to the stock status. The card suppresses it automatically for `stock: 'pre'` and `stock: 'out'`; supplier-stock products simply omit the flag. Detailed delivery times (supplier 8–14 days) belong on the Product Detail Page.
- Design-system components flip automatically (the theme re-points `--ink`, `--paper`, `--gray-*`); ink on neon fills is forced black by `nyja-theme.css`. Pick variants that work on both surfaces.
- Parity rule: switching theme must never hide content, controls, media or navigation. Before shipping a screen, check it in both themes (the Tweaks `theme` control) — every media placeholder, rule, panel and chip must remain distinguishable from its container.

## Commerce vocabulary (canonical — PDP/PLP/ProductCard/Cart/Checkout)
- Availability labels: local+in → "Në stok" · local+low → "Stok i kufizuar" · supplier (in/low) → "I porositshëm" with promise "8–14 ditë në zyrat tona" · pre → "Para-porosi" · out → "Nuk ka stok" · combination not sold → "Nuk ofrohet". `low` is a backend-supplied state; UI never derives a threshold.
- 24h eligibility = `src === 'local' && (stock === 'in' || stock === 'low') && fast === true` — one derived state for the neon pill, delivery copy and shipment grouping. `fast` alone never creates a 24h promise.
- Exact on-hand inventory is never rendered. Quantity limit = explicit `maxPerOrder` (fixture) clamped silently by inventory; the only limit copy is "Sasia maksimale u arrit."
- Signals: neon = 24h only (plus the AI search button). Discount % = ink badge. "Kurse X €" = plain text. Pre-order = status dot + CTA, never a neon badge.
- Installments: no computed monthly amount anywhere; use "Pagesë me këste · shiko opsionet" (Checkout keeps its bank caveat). Financing terms are LEGAL VERIFICATION.
- Product identity: `name` is the product ("MacBook Air 13\" M4"); the variant is shown separately ("Argjend · 16 GB / 256 GB") — never both embedded in the name on the same surface.
